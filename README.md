# 🌿 Plant Disease Detector

An AI-powered web application that detects plant leaf diseases from images using deep learning. Built with TensorFlow and Streamlit, this tool helps in early identification of crop diseases for better agricultural decisions.

---

## 🚀 Features

- 📸 Upload leaf images for instant prediction
- 🧠 Deep learning model (MobileNetV2)
- 📊 Displays top predictions with confidence scores
- 🌱 Clean and interactive Streamlit UI
- ⚡ Fast and easy to use

---

## 🛠️ Tech Stack

- Python
- TensorFlow / Keras
- Streamlit
- NumPy
- Pillow (PIL)

---

## 📂 Project Structure
├── app.py # Streamlit app
├── plant_disease_model.h5 # Trained model
├── class_names.json # Class labels
├── requirements.txt # Dependencies

---

## ▶️ Run Locally

1. Clone the repository:
git clone https://github.com/your-username/plant-disease-detector.git
cd plant-disease-detector

2. Install dependencies:
pip install -r requirements.txt

3. Run the app:
streamlit run app.py

---

## 🌐 Deployment

This app is deployed using Streamlit Cloud.

👉 Upload the project to GitHub and connect it to Streamlit Cloud for live deployment.

---

## 📸 How It Works
1. Upload a plant leaf image
2. Model processes the image
3. Displays:
• Predicted disease
• Confidence score
• Top 3 predictions
